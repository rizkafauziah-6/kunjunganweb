# 📋 Formulir Pendaftaran Journalist Academy 7.0

Proyek ini adalah aplikasi formulir pendaftaran berbasis web yang terhubung langsung dengan **Google Sheets** menggunakan **Google Apps Script** sebagai backend.  
Setiap data pendaftar akan otomatis tersimpan di spreadsheet dan dapat mengirim **notifikasi email** kepada admin maupun peserta.

---

## 🚀 Fitur Utama

- Formulir web responsif (HTML + CSS + JS)
- Terhubung otomatis ke Google Spreadsheet
- Notifikasi **email ke admin** dan **auto-reply ke peserta**
- Validasi input dan pesan sukses/error
- Mudah di-deploy tanpa server (menggunakan Google Apps Script)
